# 轻影播放器

Lite Shadow 是一款 Windows 本地影音播放器，用来播放电脑里的视频和音频。

当前版本：**1.1.2**

## 下载安装

安装包只支持 64 位 Windows 10 及以上。

[下载 QingyingSetup-1.1.2.exe](https://github.com/Sineide888/qingying/releases/download/v1.1.2/QingyingSetup-1.1.2.exe)

双击安装即可。安装不需要管理员权限，程序会装到当前用户目录。安装时可以创建桌面快捷方式。

如果 Windows 提示“已保护你的电脑”，点“更多信息”，再点“仍要运行”。安装包目前没有数字签名，所以会出现这个提示。

## 能做什么

- 播放常见本地视频和音频
- 播放列表支持文件夹分类、展开收起、Shift / Ctrl 多选和拖拽排序
- 播放中右键可暂停、逐帧、截图、调节画面，以及查看分辨率、帧率和编码
- 可自定义快捷键

## 说明

播放引擎使用 [LibVLC](https://www.videolan.org/)（LGPL-2.1-or-later）。许可说明见 `src/Qingying.Player/NOTICE.txt`。
